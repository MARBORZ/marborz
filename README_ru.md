## 🛠️ Стек

**Frontend:**
- **Vite** — Быстрый инструмент сборки
- **React 19** — Последняя версия с хуками
- **TypeScript** — Типобезопасность
- **React Router DOM** — Клиентская маршрутизация
- **react-i18next** — Интернационализация (EN, RU, NO)
- **react-hook-form** — Обработка форм
- **Framer Motion** — Анимации
- **Sass** — CSS препроцессор

**Backend:**
- **Express** — API сервер
- **Resend** — Доставка email
- **Node.js** — Runtime

## 🚀 Начало Работы

### Требования
- Node.js 18+
- Bun (менеджер пакетов)

### Установка

```bash
# Установить зависимости
bun install

# Запустить dev-сервер
bun run dev

# Собрать для продакшена
bun run build
```

Dev-сервер запускается на `http://localhost:5173`

## 🌍 Языки

Поддерживает 3 языка с cookie-персистентностью:
- **EN** — Английский (по умолчанию)
- **RU** — Русский
- **NO** — Норвежский

Выбор языка сохраняется в `lang` cookie. Первое предпочтение пользователя переопределяет автоопределение системного языка.

## 🔧 Разработка

### Добавление Компонентов

1. Создать в `src/components/ComponentName.tsx`
2. Экспортировать из `src/components/index.ts`
3. Использовать TypeScript для props
4. Следовать дизайн-токенам (без хардкода цветов)

### Добавление Страниц

1. Создать в `src/pages/PageName.tsx`
2. Добавить маршрут в `App.tsx`
3. Использовать `useTranslation()` для переводов
4. Экспортировать из `src/pages/index.ts`

### Работа с i18n

```typescript
import { useTranslation } from 'react-i18next';

export function MyComponent() {
  const { t } = useTranslation();
  return <h1>{t('home.title')}</h1>;
}
```
