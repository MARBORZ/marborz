## 📝 Пример использования

### 📥 INPUT
Нужно создать компонент для кнопки в дизайн-системе. Какой подход использовать?

### ⚙️ PROCESSING
- **Вариант A: Простой React component**
  - ✅ Быстро, простой
  - ❌ Сложно с вариантами (size, variant, state)

- **Вариант B: Component + variants (CSS Modules)**
  - ✅ Хорошо масштабируется
  - ❌ Больше кода для одного компонента

- **Вариант C: Component + CVA (Class Variance Authority)**
  - ✅ Type-safe, масштабируемо, clean API
  - ❌ Доп зависимость

### 📤 OUTPUT
**Выбор:** Вариант C (CVA)
**Обоснование:** type-safe, легко документировать варианты, масштабируется на 100+ компонентов
**Реализация:** 
- Установить `class-variance-authority`
- Создать `Button.tsx` с CVA
- Экспортировать из `components/index.ts`
**Статус:** In progress
